Accessibility Statement

Last updated: July 25, 2026

Amanda Elise is committed to making this website usable by as many people as possible, including people with disabilities.

Conformance Standard

We aim to meet the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA, which help make web content more accessible to people with disabilities.

Accessibility Features

This site uses semantic HTML landmarks, a visible skip-to-content link, sufficient color contrast, and clear keyboard focus indicators to support screen readers and keyboard navigation.

Feedback

If you encounter any accessibility barriers while using this site, please let us know so we can address them. Contact us at amanda@amandaelise.com.
